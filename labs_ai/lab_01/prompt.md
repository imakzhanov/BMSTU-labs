# Промпты для нейросетей

Промпт 1 отправляется без изменений в новый чат каждой нейросети (DeepSeek, Qwen, GigaChat, korolev-ai).
Ответ сохраняется в папку нейросети. Для отчёта фиксируется: промпт → ответ → как проверяли → результат.

---

## Промпт 1. Основное задание

```
Нужно написать Python скрипты,
которые строят векторы по набору текстов на русском языке.

Тексты лежат в папке "тексты".
Читать файлы не надо, у меня уже есть общий парсер text_parser.py в корне проекта.
Твои скрипты лежат в отдельной папке рядом с ним:

lab_vectorization/
  text_parser.py
  тексты/
  <папка нейросети>/
    main.py
    doc_wordforms.py
    doc_lemmas.py
    word_ngrams.py
    word_dependencies.py
    output/

Тексты читаются один раз в main.py, вот так:

import os, sys
sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))
from text_parser import read_texts
texts = read_texts()   # {"Анамнез/анамнез_03.txt": "текст документа", ...}

Тематика = то, что в имени до "/".

Остальные 4 файла - это модули, в каждом одна главная функция, которая принимает
словарь texts и возвращает результат (dict). Сами они файлы не читают и ничего не
сохраняют. main.py по очереди вызывает эти функции и сохраняет результат каждой
в output/ в json файл.

Что должны делать функции:
1. doc_wordforms.py - векторы документов по словоформам (слова как есть, без лемматизации)
2. doc_lemmas.py - векторы документов по начальным формам слов
3. word_ngrams.py - векторы слов и неслучайные словосочетания на основе n-грамм
4. word_dependencies.py - векторы слов и неслучайные словосочетания на основе
   синтаксического анализа зависимостей

В 3 и 4 нужны именно векторы СЛОВ, а не документов: для каждого слова (леммы) вектор его
контекстов - соседних слов в 3, синтаксически связанных слов в 4. Словосочетания отбирать
какой-нибудь мерой ассоциации, а не просто по частоте.

Ограничения:
- морфология (леммы, части речи) только через pymorphy3
- для синтаксиса парсер любой (natasha, spacy, stanza), но леммы всё равно через pymorphy3
- готовые эмбеддинги (word2vec, fasttext, bert) не использовать
- numpy, scipy, sklearn можно

Что возвращают функции и что main.py сохраняет в output/:
- doc_wordforms.json и doc_lemmas.json:
  {"Анамнез/анамнез_03.txt": {"признак": вес, ...}, ...}  - только ненулевые веса
- word_ngrams.json и word_dependencies.json:
  {"vectors": {"слово": {"контекст": вес, ...}, ...},
   "collocations": [{"phrase": "слово1 слово2", "freq": 12, "score": 5.31}, ...]}
  collocations отсортировать по score по убыванию

В ответе дай полный код всех файлов, коротко объясни какой метод выбрал в каждом скрипте
и формулы, что нужно установить через pip и как проверить что всё посчиталось правильно.
```

## Что проверять в каждом ответе

| Что | Как |
|---|---|
| Запуск | `python <папка>/main.py` без ошибок; сколько итераций правок понадобилось |
| Структура | `read_texts()` вызывается только в main.py; модули не читают файлы и не пишут в output/ |
| pymorphy3 | нет `import pymorphy2`, анализатор создаётся один раз, а не в цикле |
| Формы и леммы | в doc_wordforms есть разные признаки «кровь» и «крови», в doc_lemmas — только «кровь» |
| Дубликат | `анамнез_01.docx` и `биохимия_07.txt` — один и тот же текст: косинус их векторов должен быть 1,0 |
| Векторы слов | в vectors ключи — слова, а не имена документов; у частотных слов осмысленные ближайшие соседи |
| Словосочетания | топ-30 по score: устойчивые сочетания («биохимический анализ», «спортивный комментатор») или мусор |
