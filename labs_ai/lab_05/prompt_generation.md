# Промпт для генерации новых текстов (БЯМ)

Используй один и тот же промпт для каждой из 7 тем; для каждой теме проси 2–3 текста.
Сохраняй каждый как отдельный .txt (UTF-8) в `lab_05\generated\<Тема>\<тема>_gen_01.txt` и т.д.

Темы (точно как имена подпапок): Анамнез, Биохимия крови, Комментаторы,
Неорганическая химия, Органическая химия, Спортивная медицина, Ставки на спорт.

```
Напиши связный русскоязычный текст на тему «<ТЕМА>» объёмом 250–400 слов.
Стиль — информативный, как фрагмент учебного пособия или статьи; без заголовков,
списков и markdown, только сплошной текст абзацами. Используй терминологию темы,
не упоминай, что текст сгенерирован. Это текст №<N>: он должен отличаться по
содержанию от предыдущих текстов на ту же тему.
```

В отчёте указать: какая модель использована, дата, точный промпт.
