## Промпт 1. Основное задание

```
Нужно написать Python скрипты для кластеризации документов:
алгоритмы k-средних и c-средних (нечёткие, Fuzzy C-Means), выбор числа кластеров
методом локтя, три вида мер близости. Алгоритмы нужно реализовать САМОМУ на numpy:
KMeans из sklearn и skfuzzy не подходят, потому что не умеют менять меру близости.

Данные.
Для каждого из 50 текстов уже посчитаны векторы (tf-idf веса, неотрицательные).
Их загружает готовый модуль vectors.py из соседней папки lab_02, переписывать его не надо.
Подключать так:

import os, sys
HERE = os.path.dirname(os.path.abspath(__file__))
sys.path.insert(0, os.path.join(os.path.dirname(HERE), "lab_02"))
from vectors import AI_NAMES, VECTOR_TYPES, load_doc_vectors, cluster_of

AI_NAMES = ["deepseek", "qwen", "gigachat", "korolev-ai"]   # 4 набора векторов от разных нейросетей
VECTOR_TYPES = ["doc_wordforms", "doc_lemmas"]              # векторы по словоформам и по леммам
doc_names, features, X = load_doc_vectors(ai_name, vector_type)
# doc_names: список из 50 имён вида "Анамнез/анамнез_03.docx"
# features: список из N признаков (N порядка 3-7 тысяч, у разных наборов разное)
# X: np.ndarray формы [50, N], float, все значения >= 0, большинство нулей
cluster_of(doc_names[0])  # -> "Анамнез", настоящая тематика документа (подпапка)

Настоящих тем 7. Они НЕ используются при кластеризации, только для оценки качества
(ARI, NMI, purity) и для сравнения с найденными кластерами.

Файлы (лежат в папке lab_04/, рядом с lab_02 и lab_01):

lab_04/
  distances.py
  clustering.py
  evaluation.py
  main.py
  output/

distances.py, clustering.py, evaluation.py - модули с функциями. Они ничего не читают с диска
и ничего не сохраняют. Читает данные и сохраняет результаты только main.py.

1. distances.py
Три меры близости. Все возвращают РАССТОЯНИЕ (чем меньше, тем ближе), без циклов по парам, на numpy.
Функция pairwise_distance(A, B, measure) -> np.ndarray формы [len(A), len(B)],
measure - одна из строк "euclid", "tanimoto", "pearson":
  - "euclid"   - метрическая мера, евклидово расстояние d = sqrt(sum((x-y)^2))
  - "tanimoto" - ассоциативная мера, коэффициент Танимото (обобщённый Жаккар для весовых
                 векторов): s = (x.y) / (|x|^2 + |y|^2 - x.y), расстояние d = 1 - s
  - "pearson"  - корреляционная мера, коэффициент корреляции Пирсона между компонентами
                 двух векторов: r = cov(x, y) / (std(x) * std(y)), расстояние d = 1 - r
Нужна защита от деления на ноль (нулевой вектор, нулевое стандартное отклонение).
Для pearson посчитай через центрирование и нормировку строк и одно матричное умножение.
Сделай словарь MEASURES = {"euclid": "метрическая", "tanimoto": "ассоциативная",
"pearson": "корреляционная"} - он нужен для подписей в отчёте.

2. clustering.py
Две функции, обе принимают measure и используют pairwise_distance из distances.py:

kmeans(X, k, measure, n_init=5, max_iter=100, seed=0) -> dict
  - инициализация k-means++ с выбранной мерой (вероятность выбора ~ d^2)
  - шаг назначения: каждый документ в кластер с ближайшим центром по выбранной мере
  - шаг пересчёта: центр = среднее арифметическое векторов кластера (для всех трёх мер)
  - остановка, когда метки не меняются, либо max_iter
  - пустой кластер: перенести в него документ, самый далёкий от своего центра
  - n_init запусков с разными начальными центрами, оставить с наименьшим inertia
  - возвращает {"labels": np.ndarray[n], "centers": np.ndarray[k, N], "inertia": float, "n_iter": int}
  - inertia = сумма по документам d(x, центр своего кластера)^2 (для любой меры, одна формула)

cmeans(X, c, measure, m=2.0, n_init=5, max_iter=150, tol=1e-5, seed=0) -> dict
  - Fuzzy C-Means: матрица принадлежностей U формы [n, c], строки суммируются в 1
  - центры: v_j = sum_i(u_ij^m * x_i) / sum_i(u_ij^m)
  - принадлежности: u_ij = 1 / sum_l (d_ij / d_il)^(2/(m-1)),  d - расстояние выбранной меры;
    если d_ij = 0, то u_ij = 1, остальные 0 (отдельно обработать это место)
  - начальные U - случайные (Dirichlet), с seed
  - остановка: max|U_новая - U| < tol, либо max_iter
  - n_init запусков, оставить с наименьшей целевой функцией
  - возвращает {"u": np.ndarray[n, c], "labels": np.argmax(u, axis=1), "centers": np.ndarray[c, N],
    "inertia": float, "n_iter": int}
  - inertia = J = sum_ij u_ij^m * d_ij^2

Никакого случайного состояния вне np.random.default_rng(seed).

3. evaluation.py
  - elbow_point(ks, values) -> int: оптимальное k по методу локтя. Алгоритм: нормировать ks и
    values в [0, 1], провести прямую через первую и последнюю точки, взять k, у которого
    расстояние от точки до этой прямой максимально
  - external_metrics(true_labels, pred_labels) -> dict с ключами "ARI" (adjusted_rand_score),
    "NMI" (normalized_mutual_info_score), "purity" (доля документов, попавших в самый частый
    истинный класс своего кластера; purity напиши сам). Используй sklearn.metrics
  - silhouette(X, labels, measure) -> float: коэффициент силуэта на матрице расстояний
    pairwise_distance(X, X, measure) (sklearn.metrics.silhouette_score с metric="precomputed");
    если кластеров меньше 2 - вернуть nan

4. main.py
Для каждой пары (нейросеть, тип векторов) из AI_NAMES x VECTOR_TYPES (8 пар):
  1. загрузить X, получить настоящие метки true_labels (числа 0..6 по cluster_of)
  2. для каждого алгоритма ("kmeans", "cmeans") и каждой меры ("euclid", "tanimoto", "pearson"):
     - запустить для k = 2..15, записать inertia каждого k (кривая локтя)
     - elbow_point -> оптимальное k_opt
     - для k_opt и отдельно для k = 7 (настоящее число тем) посчитать silhouette и external_metrics
  3. сохранить в output/<нейросеть>/<тип_векторов>/:
     - elbow_curves.csv: строки - k, столбцы - "<алгоритм>_<мера>" со значением inertia
     - metrics.csv: строка на каждую пару (алгоритм, мера), столбцы: k_opt, silhouette, ARI, NMI,
       purity (для k_opt) и те же показатели с суффиксом _k7 (для k = 7)
     - labels.csv: строки - документы, столбцы - "<алгоритм>_<мера>", значения - кластер при k_opt;
       первый столбец - настоящая тематика
     - memberships_cmeans_<мера>.csv: матрица принадлежностей c-средних при k_opt (3 файла)
     - elbow_curves.png: два графика рядом (k-средних и c-средних), на каждом три линии по мерам;
       по оси Y inertia, делённая на inertia при k=2 (чтобы меры были на одной шкале),
       оптимальное k отметить маркером
  4. в конце сохранить output/comparison_summary.csv: все 8 x 6 = 48 строк с колонками
     нейросеть, тип_векторов, алгоритм, мера, k_opt, silhouette, ARI, NMI, purity, ARI_k7, NMI_k7
     и напечатать эту таблицу в консоль
CSV сохранять так: df.to_csv(path, sep=";", decimal=",", encoding="utf-8-sig", float_format="%.6g")
Графики: matplotlib.use("Agg"), подписи по-русски, plt.close(fig) после сохранения.

Ограничения:
- Python 3.12, Windows
- библиотеки: numpy, pandas, scipy, matplotlib и sklearn.metrics (только метрики качества);
  sklearn.cluster и skfuzzy не использовать
- фиксированный seed=0, результат должен воспроизводиться
- скорость: весь main.py должен считаться не дольше нескольких минут, поэтому матрицы расстояний
  считать векторизованно, а не в цикле по документам
- код с комментариями на русском: по каждой формуле комментарий, что она считает

В ответе дай полный код всех четырёх файлов, коротко опиши алгоритмы и формулы, что нужно
установить через pip и как проверить, что результат правильный.
```
