# Лабораторная 7. Перцептрон и MNIST

## Что реализовано

- Проверка приложенного примера PyTorch: сеть 784–16–16–10, 10 эпох, SGD с шагом 0.001.
- Сеть по заданию: **784–16–10, один скрытый слой**, ReLU и softmax, ошибка cross-entropy.
- `outputs/mnist_perceptron.xlsx`: прямой проход и обратное распространение ошибки на формулах листов. Все 784 пикселя используются без уменьшения изображения.
- `TrainMNIST.bas`: управление повторением эпох в LibreOffice. Макрос только копирует рассчитанные ячейками веса и вызывает пересчет. В нем нет вычисления нейросети или градиентов.
- `experiment.py`: независимая проверка формул через NumPy, выполнение исходного ноутбука и эксперимент с размером обучающей выборки.

## Как открыть и обучить в LibreOffice

1. Открыть `outputs/mnist_perceptron.xlsx` в Calc, разрешить пересчет формул. При необходимости нажать Ctrl+Shift+F9.
2. В меню «Сервис → Макросы → Управление макросами → Basic» создать модуль **в этом документе**, вставить содержимое `TrainMNIST.bas`.
3. Сохранить как `.ods`, чтобы сохранить Basic-макрос вместе с таблицей.
4. На Summary задать шаг обучения B5 и число следующих эпох B6. Запустить макрос `TrainMNIST`.
5. Посмотреть точность и ошибку на Summary. Повторный запуск продолжает обучение. `ResetMNIST` возвращает исходные веса и очищает историю.

Макрос останавливается при достижении цели B8 на обучении или после B6 новых эпох. Значение 0.999 на 100 примерах требует распознать все 100 правильно. Это не гарантирует такой же точности на новых изображениях.

Макрос не требует доступа к сети или файловой системе. Одновременное сохранение двух матриц перед обновлением важно: градиенты обеих матриц должны вычисляться при одних и тех же старых весах.

### Что находится на листах

| Лист | Назначение |
|---|---|
| Summary | Параметры, точность на train/test, ошибка, история эпох, статистические оценки |
| Forward | Скрытые нейроны, выходные оценки, softmax, предсказанная цифра, ошибка |
| Backward | Ошибки выходного и скрытого слоев для вычисления градиентов |
| Weights | Текущие, следующие и начальные веса |
| Data | 100 обучающих и 100 тестовых изображений, метки и 784 пикселя / 255 |
| Curve | Эксперимент по зависимости точности от числа обучающих примеров |

Сеть в таблице обучается на небольшой сбалансированной выборке (10 примеров каждой цифры), чтобы работа листов оставалась обозримой. Ее тест из 100 отдельных изображений служит демонстрацией; исследование объема обучения использует полный тест MNIST из 10 000 изображений.

## Простыми словами

Картинка — это 784 числа: яркости пикселей. Каждый из 16 скрытых нейронов складывает пиксели со своими весами. Отрицательный результат заменяется нулем (ReLU). Затем 10 выходных нейронов формируют оценки цифр от 0 до 9. Softmax превращает их в вероятности. Ответ сети — цифра с наибольшей вероятностью.

Во время обучения правильная цифра известна. По несовпадению ответа с меткой вычисляются поправки к весам. На каждом шаге веса немного меняются в сторону уменьшения ошибки. Эпоха в таблице — один шаг по среднему градиенту всех 100 обучающих примеров.

## Как оценивается необходимое число примеров

Точность **0.999 = 99.9%** — одна ошибка на тысячу в среднем. Обучающая точность показывает запоминание примеров. Тестовая точность показывает качество на новых изображениях. Для оценки количества данных исследуется прежде всего тестовая точность.

В эксперименте используется та же архитектура 784–16–10. Для N = 100, 500, 2000, 10000, 30000, 60000 выполняются три независимых запуска. Выборки вложенные и приблизительно сбалансированные. Обучение: SGD, шаг 0.1, batch 128, максимум 60 эпох. Остановка при train accuracy >= 0.999 либо по лимиту эпох. Тест не используется при выборе эпох и остановке.

Тестовые результаты всех N являются исследовательской кривой, а не финальной независимой проверкой подобранной по ней новой модели. Три запуска показывают разброс, но не обеспечивают узкого доверительного интервала.

Для приблизительной экстраполяции подгоняется `error(N) = a * N^(-b) + c`. Если c >= 0.001, эта подгонка не дает конечной оценки N для цели 0.999. Это ограничение модели экстраполяции и проведенного эксперимента, **не доказательство невозможности** достичь цели другой архитектурой или способом обучения. Нельзя честно выдавать придуманное число обучающих картинок, когда цель не достигнута.

### Зачем приложен PDF и что дает Чебышев

Для независимых результатов проверки «верно/неверно» дисперсия равна `p(1-p)`, а в худшем случае 0.25. Неравенство Чебышева дает

`N >= variance / ((1-P) * eps^2)`.

Здесь P — доверие, eps — допустимая **погрешность измерения точности**, а не сама точность. При P=0.99 и eps=0.001:

- худший случай: N >= 25 000 000;
- если предположить p=0.999: N >= 99 900.

Оба числа относятся к размеру **проверочной** выборки. Они не говорят, сколько примеров нужно нейросети для обучения. Подстановка p=0.999 также не доказывает, что эта точность достигнута.

Дополнительно при отсутствии ошибок на независимой проверке точная односторонняя биномиальная граница требует `N >= ceil(ln(1-P)/ln(0.999)) = 4603` для доверия 99%. Это другой критерий: нижняя граница точности при нуле ошибок, а не оценка с погрешностью ±0.001. Если ошибки есть, применяется общая биномиальная граница.

## Воспроизведение Python-экспериментов

Установить зависимости из `requirements.txt` в свое окружение Python. MNIST уже находится в `data/MNIST/raw`.

```bash
python experiment.py sheet
```

```bash
python experiment.py notebook
```

```bash
python experiment.py curve
```

`notebook` запускает кодовые ячейки предоставленного примера. Установка пакетов вынесена отдельно; рисунки сохраняются вместо открытия окон; модель сохраняется в results. В пробном вызове `model(X)` вход переносится на устройство модели — это исправляет потенциальную ошибку при CUDA. Алгоритм и гиперпараметры примера сохраняются. Для воспроизводимости установлен seed 42.

`node build_sheet.mjs` собирает таблицу с помощью `@oai/artifact-tool`, проверяет все вероятности и обе матрицы следующего шага против NumPy и сохраняет XLSX. Это средство разработки, для открытия готовой таблицы Node.js не нужен.
