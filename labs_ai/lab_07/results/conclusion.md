**Граница проверки:** непосредственно LibreOffice в среде не установлен. Выполнение Basic-макроса в Calc и сохранение после нативного пересчета здесь не проверены. NumPy-эталон той же небольшой таблицы после 300 эпох: train 100.0%, test 70.0%. Это отдельный эталонный прогон, не результат выполнения макроса Calc.
На этой фиксированной обучающей выборке из 100 картинок цель train >= 0.999 впервые достигнута на эпохе 29 (train 100.0%, test 68.0%). Поэтому при трактовке цели как запоминания обучающих примеров 100 оказалось достаточно в этом прогоне; минимальность такого N не установлена.

## Размер обучающей выборки

Сеть 784–16–10, SGD 0.1, batch 128, до 60 эпох. Три seed для каждого N. Остановка по обучающей точности 0.999 либо лимиту эпох. Для теста во всех запусках используются 10 000 отдельных исходных тестовых изображений.

| N обучения | Train, среднее | Test, среднее | Test, СКО |
|---:|---:|---:|---:|
| 100 | 0.9767 | 0.7044 | 0.0176 |
| 500 | 0.9793 | 0.8542 | 0.0097 |
| 2000 | 0.9768 | 0.8939 | 0.0040 |
| 10000 | 0.9643 | 0.9231 | 0.0093 |
| 30000 | 0.9697 | 0.9439 | 0.0043 |
| 60000 | 0.9710 | 0.9555 | 0.0020 |

Лучшая средняя тестовая точность: **95.55%** при N = 60000. Цель 99.9% в этом эксперименте не достигнута. По имеющимся данным нельзя назвать подтвержденное достаточное число обучающих примеров.

Подгонка test error = a*N^(-b)+c:

```json
{
  "a": 2.494681412502864,
  "b": 0.49844900359174493,
  "c": 0.04239207837393914,
  "estimated_n_for_0999": null
}
```

Если оценка N отсутствует, выбранная подгонка не пересекает целевую ошибку 0.001. Это не доказывает недостижимость цели другими методами. Качество зависит от архитектуры, оптимизации и сложности изображений, а не только от числа примеров.

## Статистическая оценка по приложенному PDF

Чебышев: N >= sigma² / ((1-P)*eps²). При P=0.99, eps=0.001: N=25 000 000 для sigma²=0.25; N=99 900 при предположении p=0.999 и sigma²=p(1-p). Это объем ПРОВЕРОЧНОЙ выборки для оценки доли с заданной погрешностью. Подменять этим числом размер обучающей выборки нельзя.

Дополнительная точная биномиальная оценка: если на независимом тесте нет ни одной ошибки, 4603 проверки достаточно для односторонней нижней границы p >= 0.999 с доверием 99%. Условие нулевого числа ошибок обязательно.

В PDF есть опечатка: 826446 соответствует eps=0.0055, тогда как в формуле 4.4.3 напечатано 0.005. При eps=0.005 получается 1 000 000.

## Вывод

Пример проверен, однослойный по скрытым слоям перцептрон реализован на формулах листов, численные формулы проверены независимо. Исследование показывает рост тестовой точности при увеличении N, но не подтверждает 0.999. Честный результат оценки: достаточный объем обучения для этой цели не установлен в диапазоне до 60 000 при выбранных параметрах. Числа из неравенства Чебышева характеризуют точность проверки, а не способность сети обучиться.
